MISSION

Le Dashboard Client est désormais quasiment terminé.

Maintenant il faut reconstruire entièrement les espaces :

• Agent CPI
• Administrateur

Le principe est simple :

ABSOLUMENT TOUT ce que voit le client provient de ces deux interfaces.

Ces dashboards deviennent le véritable ERP de CPI CHUES.

Ils pilotent :

- les dossiers
- les validations
- les documents
- les signatures
- les chantiers
- les photos
- les vidéos
- les notifications
- les décaissements CBAO
- les commentaires
- les historiques
- les utilisateurs
- les projets
- les statistiques

L'objectif est d'obtenir un logiciel digne d'une banque ou d'un promoteur immobilier.

RÈGLE N°1

Le Dashboard Client ne possède AUCUNE logique métier.

Il ne fait qu'afficher les données.

Toutes les données sont créées depuis :

• Dashboard Agent CPI

ou

• Dashboard Administrateur
