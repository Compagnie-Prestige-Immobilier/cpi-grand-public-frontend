MISSION DU JOUR

Concevoir UNIQUEMENT la page :

📋 MA DEMANDE

Cette page doit permettre au client de :

• créer une nouvelle demande ;

• compléter une demande existante ;

• suivre son état d'avancement ;

• transmettre les documents nécessaires ;

• consulter les informations principales de sa demande.

L'objectif est que le client puisse gérer toute sa demande depuis une seule page.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OBJECTIF UX

La page doit donner l'impression d'un parcours simple, moderne et guidé.

Le client ne doit jamais se sentir perdu.

Chaque étape doit être claire.

L'interface doit inspirer confiance comme une plateforme bancaire.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STRUCTURE

==================================================

1. HEADER

==================================================

Afficher :

• Ma demande

• Numéro de dossier

• Date de création

• Statut de la demande

Le statut doit être affiché sous forme de badge.

Exemples :

🟢 Validée

🟠 En cours d'étude

🔵 En attente de documents

🔴 Demande incomplète

⚪ Brouillon

Ajouter une barre de progression indiquant le pourcentage d'avancement de la demande.

==================================================

2. FORMULAIRE DE DEMANDE

==================================================

Le formulaire constitue la partie principale de la page.

Créer un formulaire professionnel découpé en plusieurs sections.

Exemple :

IDENTITÉ

• Nom

• Prénom

• Date de naissance

• Sexe

• Nationalité

• Téléphone

• Email

• Adresse

------------------------------------------------

PROFIL

Choix du profil :

○ Fonctionnaire

○ Secteur public

○ Secteur privé

○ Chef d'entreprise

○ Profession libérale

○ Indépendant

○ Diaspora

Selon le profil choisi, prévoir la possibilité d'afficher des champs spécifiques (formulaire dynamique).

------------------------------------------------

PROJET

• Nature du projet

• Montant souhaité

• Durée souhaitée

• Apport personnel (si applicable)

• Ville

• Région

• Commentaires

==================================================

3. DOCUMENTS REQUIS

==================================================

Créer une section moderne d'upload.

Chaque document apparaît dans une carte indépendante.

Exemples :

📄 Pièce d'identité

📄 Justificatifs de revenus

📄 Relevés bancaires

Les cartes doivent afficher :

• nom du document

• statut

• bouton Télécharger

• bouton Remplacer

• aperçu lorsque le document existe

• taille du fichier

• date d'envoi

Le système doit afficher automatiquement :

✔ Reçu

⏳ En attente

❌ Refusé

avec le motif du refus lorsque nécessaire.

==================================================

4. RÉSUMÉ DE LA DEMANDE

==================================================

Afficher :

Numéro de dossier

Date de dépôt

Profil

Montant demandé

Durée

Agence de suivi

Conseiller

Statut actuel

Référence de la demande

==================================================

5. HISTORIQUE DE TRAITEMENT

==================================================

Créer une timeline chronologique.

Exemples :

✔ Demande créée

✔ Documents reçus

✔ Analyse démarrée

✔ Conseiller affecté

✔ Validation effectuée

Chaque événement contient :

• icône

• date

• heure

• description

==================================================

6. ACTIONS DISPONIBLES

==================================================

Créer une dernière carte contenant les actions possibles.

Par exemple :

Enregistrer le brouillon

Modifier la demande

Compléter les informations

Télécharger le récapitulatif

Contacter le conseiller

Les boutons doivent être modernes, visibles et facilement accessibles.
