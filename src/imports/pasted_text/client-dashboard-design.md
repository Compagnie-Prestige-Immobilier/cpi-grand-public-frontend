OBJECTIF

Créer un Tableau de bord moderne, premium, intuitif et extrêmement simple.

Le client doit comprendre immédiatement :

• sa situation financière ;
• les informations essentielles ;
• les actions importantes à réaliser.

Le Tableau de bord ne doit contenir qu'une vue synthétique.

Les informations détaillées seront disponibles dans les autres menus.

Le résultat doit être comparable aux meilleurs logiciels SaaS modernes comme :

• Stripe
• Qonto
• HubSpot
• Notion
• Revolut Business
• Monday.com

tout en conservant l'identité visuelle de CPI Immobilier.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STRUCTURE À CRÉER

==================================================

1. HEADER

==================================================

Créer un header élégant affichant :

• Bonjour [Nom du client]

• Message de bienvenue

• Date du jour

• Avatar du client

• Icône Notifications

Interface très épurée.

Beaucoup d'espace blanc.

Design premium.

==================================================

2. MES MÉTRIQUES

==================================================

Créer une rangée horizontale de cartes KPI.

Chaque carte possède :

• une icône moderne

• un titre

• une valeur importante

• une couleur discrète

• une animation hover

• une légère ombre

• des coins arrondis

Les KPI sont :

💰 Montant financé

📅 Montant par échéance

✅ Nombre de mois payés

💳 Montant déjà payé

⏳ Nombre de mois restants

🚨 Alertes réelles

Les alertes utilisent un badge :

Vert

Orange

Rouge

Exemple :

Aucune alerte

ou

Une échéance en retard

Les KPI constituent le bloc principal du Tableau de bord.

==================================================

3. ACTIONS RAPIDES

==================================================

Créer une carte contenant uniquement :

📄 Transmettre un document

📋 Consulter ma demande

📁 Ouvrir mon dossier

🏗 Accéder à mon chantier

📞 Contacter mon conseiller

Créer de grands boutons modernes.

Animations discrètes.

Très bonne accessibilité.

==================================================

4. DERNIÈRES ACTIVITÉS

==================================================

Créer une timeline moderne.

Afficher uniquement les cinq dernières activités.

Exemples :

✔ Paiement enregistré

✔ Document validé

✔ Rendez-vous confirmé

✔ Nouveau document disponible

✔ Nouveau message CPI

Chaque activité contient :

• une icône

• une date

• une heure

• une courte description

Design compact et élégant.

INTERACTIONS

Toutes les cartes doivent disposer :

• d'un effet hover

• d'une transition fluide

• d'une légère élévation

• d'une animation des compteurs

Les boutons :

• hover

• clic

• animation subtile

La timeline :

• animation d'apparition progressive

Ne créer aucune section concernant :
